# MATIN CHESS — Desktop Edition 🏆♟

نسخهٔ دسکتاپ ارتقایافتهٔ بازی شطرنج **MATIN CHESS** — ظاهر و حس نسخهٔ اصلی پایتون،
همراه با تمام امکانات نسخهٔ اندروید و بیشتر.

**سازندگان / Creators:** متین کتویی زاده • امیرمحمد گلستان
*(Matin Katooei-zadeh & AmirMohammad Golestan)*

---

## اجرا / Run

```bash
python main.py
```

فقط کتابخانهٔ استاندارد پایتون (3.9+) — **هیچ پکیجی نصب نمی‌شود.**
صداها (حرکت/گرفتن) داخل خود برنامه جاسازی شده‌اند و بدون اینترنت کار می‌کنند.

```bash
python main.py --selftest   # آزمون سلامت بدون باز کردن پنجره
python main.py --demo       # تور نمایشی ربات‌دربرابرربات (برای ضبط ویدیو)
```

## ساختار پروژه / Layout

| مسیر | توضیح |
|---|---|
| `main.py` | نقطهٔ ورود (اجرای بازی، selftest، demo) |
| `matin_chess/constants.py` | ثابت‌ها، تم‌ها، رنگ‌های صفحهٔ ولتریکس |
| `matin_chess/core.py` | هستهٔ شطرنج (قلعه، آن‌پاسان، ترفیع، قانون ۵۰ حرکت، تکرار) |
| `matin_chess/engine.py` | موتور AI + سیستم نبرد ربات‌ها و نردبان سطح‌ها |
| `matin_chess/audio.py` | صداهای واقعی move-self / capture + نت‌ها و موسیقی |
| `matin_chess/app.py` | رابط کاربری (منو، بازی، spectate، تنظیمات، …) |
| `matin_chess/content.py` | درس‌های آکادمی و تمرین‌های مات |
| `matin_chess/systems.py` | آمار، ذخیره‌سازی، PGN، رتبه‌بندی تورنمنت |
| `assets/` | آیکون و فایل‌های mp3 اصلی صداها |

## سیستم نبرد ربات‌ها / Bot battle system

| ربات | سطح‌ها | حداکثر قدرت |
|---|---|---|
| **MATIN BOT** ♚ | ۲۰ سطح | موتور کامل متین (عمق ۷) |
| **VELTRIX** ⚡ | ۸ سطح + ۳ مدل رسمی (فست/لایت/های) | Veltrix بدون محدودیت (High) |
| **STOCKFISH** 🐟 | ۱۰ سطح | قدرت کامل آخرین نسخه |
| **BERSERK** 🐻 | ۱۰ سطح | سبک حمله‌ای |
| **LOZZA** 🦎 | ۱۰ سطح | عمق‌محور، پوزیشنال |
| **GARBOCHESS** ♞ | ۱۰ سطح | زمان‌محور، تاکتیکی |
| **FAIRY-STOCKFISH** 🧚 | ۱۰ سطح | تحرک‌محور |

- **سطح ۱** هر ربات عمداً خیلی ضعیف است (برای تازه‌کارها)؛ نه بدترین حرکت، اما واقعاً قابل‌شکست
- هر سطح پله‌پله قوی‌تر می‌شود تا سطح آخر = قدرت کامل همان ربات
- هر ربات شخصیت ارزیابی و کتاب شروع خودش را دارد؛ بازی‌شان واقعاً متفاوت است
- «مشاهده بازی هوش مصنوعی»: دو ربات دلخواه را به هم بیندازید و تماشا کنید

## طراحی صفحه / Board design

طراحی صفحهٔ شطرنج (خانه‌ها، هایلایت‌ها، مهره‌های دولایه، مختصات، نشانگر حرکت)
**دقیقاً از پروژهٔ [Veltrix-Chess-bot](https://github.com/amirmhmdglstan-stack/Veltrix-Chess-bot)** برداشته شده —
پرچم‌های تخت، مهرهٔ توپر با دورخط کنتراستی، نقطهٔ سبز/حلقهٔ قرمز برای حرکت‌های قانونی،
هایلایت سبز آخرین حرکت و ۸ تم رنگی.

## رفع باگ‌ها نسبت به نسخهٔ اصلی / Bug fixes

1. `winsound.بازیSound` → `winsound.PlaySound` (خرابی جایگزینی متن)
2. پیام برد هوش مصنوعی اشتباه بود («بازیکن برنده شد») → اصلاح شد
3. متن کامل درس ۷ آکادمی نمایش داده نمی‌شد → اصلاح شد
4. تمرین‌های مات هر حرکت مات‌کننده را قبول می‌کنند (نه فقط حرکت هدف)
5. **برندهٔ کیش‌ومات برعکس بود** → اصلاح شد
6. گزینهٔ «درباره» به منو وصل شد
7. **بازچینش جدید:** در نسخهٔ اصلی کدِ تمرین (`click_training`) هرگز به کلیک وصل نبود —
   کلیک‌ها به مسیر عادی بازی می‌رفت، هدف تمرین بررسی نمی‌شد و هوش مصنوعی داخل تمرین جواب می‌داد!
8. `TournamentEngine.rank()` همیشه `False` برمی‌گرداند (ایندکس خراب) → اصلاح شد
9. تبدیل پیاده واقعی: پنجرهٔ انتخاب وزیر/رخ/فیل/اسب (قبلاً همیشه وزیر)
10. بازی‌های تمام‌شده دیگر ذخیره/اداده نمی‌شوند
11. صدا روی همهٔ سیستم‌عامل‌ها پخش می‌شود (نه فقط ویندوز): winsound / aplay / paplay / ffplay / afplay
12. ربات بعد از تعویض حالت بازی دیگر «حرکت سرگردان» انجام نمی‌دهد (نگهبان حالت)
