# MATIN CHESS — Android Edition 🏆♟

بازی شطرنج **MATIN CHESS** — نسخهٔ اندروید ساخته‌شده از بازی تک‌فایلی پایتون (tkinter)، با همان ظاهر و امکانات، اما کاملاً واکنش‌گرا برای موبایل.

## ساختار مخزن / Repository layout

| مسیر | توضیح |
|---|---|
| `www/index.html` | کل بازی اندروید (HTML/CSS/JS تک‌فایل؛ موتور شطرنج + رابط واکنش‌گرا) |
| `desktop/MATIN_CHESS_FINAL.py` | نسخهٔ دسکتاپ پایتون (رفع‌شده — باگ‌های نسخهٔ اصلی اصلاح شده) |
| `android/` | پروژهٔ Capacitor/Android (تولیدشده با `cap add android`) |
| `assets/` | آیکون و اسپلش برای `@capacitor/assets` |
| `.github/workflows/build-apk.yml` | ساخت خودکار APK با GitHub Actions + انتشار Release |

## ساخت APK با GitHub Actions

- هر push روی `main` → ساخت **APK امضاشده** به‌عنوان artifact.
- push یک تگ مثل `v1.0.0` → ساخت APK + ساخت خودکار **GitHub Release** و پیوست APK به آن.

دانلود آخرین نسخه از بخش [Releases](../../releases).

## رفع باگ‌های نسخهٔ اصلی (desktop)

1. `winsound.بازیSound` → `winsound.PlaySound` (خرابی ناشی از جایگزینی متنی)
2. پیام برد هوش مصنوعی اشتباه بود («بازیکن برنده شد») → اصلاح شد
3. متن کامل درس ۷ آکادمی هرگز نمایش داده نمی‌شد (نام کلید ناهمخوان) → اصلاح شد
4. تمرین‌های مات فقط حرکت هدف خاص را قبول می‌کردند؛ حالا هر حرکت مات‌کننده پذیرفته است
5. **برندهٔ کیش‌ومات برعکس بود** — جام قهرمانی وقتی نشان داده می‌شد که شما مات می‌شدید! → اصلاح شد
6. گزینهٔ «درباره» به منو وصل نشده بود → وصل شد

## اجرای نسخهٔ دسکتاپ

```bash
python3 desktop/MATIN_CHESS_FINAL.py
```

فقط کتابخانهٔ استاندارد پایتون (بدون نصب هیچ پکیجی). روی ویندوز صدا دارد؛ روی سایر سیستم‌عامل‌ها بی‌صدا اجرا می‌شود.

## توسعه

```bash
npm ci
npx cap sync android
npx cap open android   # باز کردن در Android Studio
```
