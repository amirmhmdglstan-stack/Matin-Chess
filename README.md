## 🪟 نسخهٔ ویندوز (v3.3.0 — Windows Desktop Edition)

همان بازی اندروید — همان ظاهر، همان متن‌های فارسی، همان موتورها — روی ویندوز،
با پوستهٔ بومی **Tauri 2** (به‌جای Electron؛ حدود ۷۰ مگابایت کوچک‌تر، همان محتوا).

```bash
cd windows
npm install
npx tauri dev    # اجرا از سورس
npx tauri build  # ساخت EXE (portable + setup)
```

**تازه‌های v3.3.0:** سطح آخر هر موتور = **بی‌سقف زمانی واقعی** (جست‌وجوی عمق ۳۰ بدون movetime؛ در بازی زمان‌دار موتور خودش ساعتش را
مدیریت می‌کند؛ متین‌بات عمق ۱۲/۹۰ ثانیه) • **۱۷ تم کلی برنامه** (۱۵ تیره + ۲ روشن: روز و کاغذ) — پس‌زمینه و پنل‌ها و دکمه‌ها
با هم عوض می‌شوند • شمارندهٔ زندهٔ زمان/عمق فکر • رفع باگ‌های تماشا در پس‌زمینه، ساعت کهنهٔ ولتریکس، دیالوگ فایل و نشت حافظه.

**تازه‌های v3.2.0:** سطح آخر هر موتور = تمام قدرت • وارد کردن/خروجی موتورها با فایل `.mceng` برای انتقال بین کامپیوترها •
رفع باگ صداهای پس از خروج از بازی و هنگ بعد از بستن مسابقه.

- **ظاهر و متن‌ها دقیقاً همان نسخهٔ اندروید** (دارک داشبورد + طلایی، تمام صفحه‌ها و مودال‌ها)
- **آهنگ صفحهٔ اصلی** (`theme.mp3`) فقط در منوی اصلی با وقفهٔ ۳ ثانیه — هرگز داخل بازی
- **صدای واقعی** حرکت (`move-self.mp3`) و گرفتن مهره (`capture.mp3`) برای همهٔ حرکت‌ها — بازیکن یا ربات
- **هیچ موتوری از پیش نصب نیست** (جز متین بات) — همهٔ ربات‌ها (ولتریکس، استاک‌فیش ۶→۱۹،
  برسرک ۱۲/۱۳/۱۴، لوزا، گاربوچس، فری-استاک‌فیش) داخل خود برنامه از **سورس رسمی سازنده** دانلود
  و در حافظهٔ خود بازی نصب می‌شوند — مثل نسخهٔ اندروید
- مشاهدهٔ ربات در برابر ربات، آکادمی، تمرین‌ها، ذخیره/بارگذاری، PGN، تم‌ها — همهٔ امکانات اندروید

ساخت خودکار EXE: تگ `v*` → ورک‌فلوی `build-windows.yml` → **GitHub Release** با دو فایل:
`MATIN-CHESS-vX.Y.Z-windows-portable.exe` (بدون نصب) و `...-windows-setup.exe` (نصب‌کننده).

## ساخت با GitHub Actions

- push روی `main` → ساخت **EXE ویندوز (Electron)** به‌عنوان artifact.
- push یک تگ مثل `v3.0.0` → انتشار خودکار **GitHub Release** شامل EXE ویندوز + APK اندروید.
- ورک‌فلوی قدیمی EXE پایتونی (`build-exe.yml`) فقط با اجرای دستی (workflow_dispatch) کار می‌کند.

دانلود آخرین نسخه از بخش [Releases](../../releases).

## امکانات نسخهٔ اندروید

- موتورهای واقعی WASM (Stockfish 6-19، Berserk 12/13/14، Fairy، Lozza، Garbochess، Veltrix)
  با دانلود درون‌برنامه‌ای و نردبان نسخه
- بازی دونفره روی یک گوشی + ساعت ∞/10/5/3 دقیقه
- آکادمی ۱۰ درسی، ۱۰ تمرین «مات در یک»
- ۱۲ طرح صفحه، ۴ سبک مهره، ۱۰ تم رابط، رنگ دستی خانه‌ها
- ذخیره/بارگذاری JSON و MCGX فشرده، خروجی PGN، آمار و دستاوردها
- طراحی واکنش‌گرا (تقریباً همهٔ رزولوشن‌های موبایل، عمودی و افقی)
