# MATIN CHESS 🏆♟

بازی شطرنج **MATIN CHESS** — در دو نسخهٔ رسمی:

| نسخه | مسیر | توضیح |
|---|---|---|
| 🖥 **Desktop (Windows/Linux/macOS)** | `desktop/` | پایتون خالص، بدون هیچ پکیج خارجی؛ EXE ویندوزی با GitHub Actions |
| 📱 **Android (APK)** | `www/` + `android/` | تک‌فایل HTML/JS واکنش‌گرا داخل Capacitor |

## نسخهٔ دسکتاپ (v2.0.0 — ارتقایافته)

```bash
python desktop/main.py
```

- **سیستم نبرد ربات‌ها:** ۷ ربات — MATIN BOT (۲۰ سطح)، VELTRIX (۸ سطح + مدل‌های رسمی
  فست/لایت/های)، STOCKFISH، BERSERK، LOZZA، GARBOCHESS، FAIRY-STOCKFISH (هرکدام ۱۰ سطح)
- **سطح ۱ واقعاً آسان** است و هر سطح پله‌پله تا قدرت کامل همان ربات قوی می‌شود
- **مشاهدهٔ مسابقهٔ ربات در برابر ربات** (spectate) با انتخاب ربات و سطح هر طرف
- **صدای واقعی** حرکت (`move-self.mp3`) و گرفتن مهره (`capture.mp3`) برای همهٔ حرکت‌ها — جاسازی‌شده در خود برنامه
- **طراحی صفحهٔ شطرنج از پروژهٔ Veltrix-Chess-bot** (خانۀ تخت، مهرهٔ دولایه، ۸ تم رنگی)
- **تبدیل پیادهٔ واقعی** (انتخاب وزیر/رخ/فیل/اسب)
- بروزرسانی خودکار: بنر «نسخهٔ جدید» در صفحهٔ اصلی وقتی Release تازه‌ای منتشر شود
- قوانین کامل شطرنج (قلعه، آن‌پاسان، ترفیع، ۵۰ حرکت، تکرار سه‌باره)، آکادمی ۱۰ درسی،
  ۱۰ تمرین مات، دونفره + ساعت، ذخیره/بارگذاری JSON و MCGX، خروجی PGN، آمار و دستاوردها
- همهٔ باگ‌های شناخته‌شدهٔ نسخهٔ اصلی پایتون رفع شده‌اند (فهرست کامل در `desktop/README.md`)

## ساخت EXE با GitHub Actions

- push روی `main` → ساخت **EXE ویندوز** به‌عنوان artifact (هر دو ورک‌فلوی APK و EXE).
- push یک تگ مثل `v2.0.0` → ساخت APK + EXE و انتشار خودکار **GitHub Release** با هر دو فایل.

دانلود آخرین نسخه از بخش [Releases](../../releases).

## ساخت APK با GitHub Actions

- ورک‌فلوی `build-apk.yml` (مثل قبل): APK امضاشده + Release روی تگ.

## امکانات نسخهٔ اندروید

- موتورهای واقعی WASM (Stockfish 6-19، Berserk 12/13/14، Fairy، Lozza، Garbochess، Veltrix)
  با دانلود درون‌برنامه‌ای و نردبان نسخه
- بازی دونفره روی یک گوشی + ساعت ∞/10/5/3 دقیقه
- آکادمی ۱۰ درسی، ۱۰ تمرین «مات در یک»
- ۱۲ طرح صفحه، ۴ سبک مهره، ۱۰ تم رابط، رنگ دستی خانه‌ها
- ذخیره/بارگذاری JSON و MCGX فشرده، خروجی PGN، آمار و دستاوردها
- طراحی واکنش‌گرا (تقریباً همهٔ رزولوشن‌های موبایل، عمودی و افقی)
